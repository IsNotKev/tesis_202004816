# 📱 Tesis 202004816  
**Aplicación móvil** desarrollada como parte de mi proyecto de tesis para la carrera de Ingeniería en Ciencias y Sistemas.  

La aplicación recomienda rutinas de ejercicios de fuerza y resistencia para principiantes, e incluye un módulo de **corrección postural** usando visión por computadora.
